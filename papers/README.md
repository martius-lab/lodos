# Papers

This folder contains the publications needed to understand the inner workings of Lodos.

| paper | contents |
|---|---|
| `lodos_precursor.pdf` | the precursor to the Lodos framework, presented at the [Contact-Rich Robotics: Control and Representation workshop](https://cr2-icra.github.io/) in ICRA 2026. |
| `lodos_v1.pdf` | *(Currently under review)* The first version of the Lodos framework, introducing the collision detection framework and the "contact-group reparameterization idea". |
| `lodos_v2.pdf` | *(Currently at an extended abstract stage)* The current version of the framework, with improvements on contact dynamics. |
| `contact_tutorial.pdf` | A self-contained tutorial providing complete mathematical derivations of the most commonly employed transcriptions, convex relaxations, and numerical solution routines in modern discrete-time-stepping methods for simulating cone-complementarity-based contact dynamics. |
